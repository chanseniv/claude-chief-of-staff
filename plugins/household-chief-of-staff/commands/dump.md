The user is offloading their working memory. Load the `household-chief-of-staff` skill.

If $ARGUMENTS is empty, say: "Go. Anything and everything, any order. I'll sort it." Then wait.

## Sort the dump

For each item, decide:

- **Calendar item** (has a date or time) → propose the event (draft only; create it after approval if a calendar is connected).
- **Task** → rewrite it as a tiny next physical action, with an owner (me / partner / shared) and a due date if there is one.
- **Waiting on someone** → note who, and since when.
- **Worry** → if there's a fact you can check now, check it. Otherwise, mark it "actionable later" (schedule it) or "not in my control" (acknowledge it briefly, then let it go).
- **Idea / someday** → parking lot.
- **Duplicate of something already tracked** → merge, and say so.

## Give back

1. "Got it all. Nothing's lost." Then a count: X tasks, Y calendar items, Z parked.
2. **The one thing to do next** (your recommendation), with its tiny first step.
3. A compact sorted list, grouped as above.
4. Anything for the partner, as a single draft message they can approve.

Write it all into `tasks.md`, then read back the changed sections as proof. Before adding an item, check `tasks.md` and the calendar for an existing entry, so you don't create duplicates.
