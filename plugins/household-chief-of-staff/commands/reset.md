description: Evening shutdown. Note what closed, set up tomorrow, get the worries out of your head.
---

Run the evening reset. Load the `household-chief-of-staff` skill. Target: 5 minutes.

1. **Wins first.** From `tasks.md`, the calendar, and the conversation, name 1-3 specific things that got done today, including small ones. Move them to "Done this week."
2. **What's still open:** a quick check of today's top three. For each one not done, ask (or recommend): move to tomorrow, park, or drop? No guilt. If something keeps slipping, suggest a change to the system (a different time, a smaller step, a hand-off).
3. **Tomorrow's first moves:** the first two fixed points tomorrow (with leave-by times), anything the kids need by the door (spirit day, library books, forms, lunch), and any pet item due.
4. **Partner sync (optional):** if anything for tomorrow involves the partner, draft one short message.
5. **Worry offload:** "Anything still buzzing?" For each worry, check the facts if you can, then mark it *scheduled* (with a time) or *parked*. If they've opted into a worry window, put the rest there.
6. **Close:** one line, e.g. "Tomorrow is set up. Nothing's lost. You can put it down."

Update `tasks.md` and read back what changed.
